COMO APLICAR
1. Faça backup/commit da pasta atual.
2. Copie o conteúdo do pacote sobre D:\cactus-burguer.
3. NÃO apague a pasta .git.
4. Rode:
   npm install
   npm run build
   npm run preview
5. Teste PC e iPhone.
6. Antes do push, rode:
   git diff --check
   git status

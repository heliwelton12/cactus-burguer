# v0.6.1 — Acabamento pré-deploy

## Objetivo
Fechar o pacote técnico antes do próximo deploy sem alterar o fluxo aprovado do cardápio.

## Alterações
- favicon oficial do Cactchô em ICO, PNG e Apple Touch Icon;
- hero responsivo em AVIF/WebP (640, 960 e 1080 px), preservando a mesma arte;
- preload responsivo do hero para melhorar LCP;
- contraste dos botões principais do Cactchô ajustado para WCAG;
- ProductModal carregado sob demanda;
- Cactchô/Rive separado em chunk e ativado após idle, reduzindo trabalho inicial;
- fallback estático do Cactchô se o arquivo Rive falhar;
- proteção contra reprocessamento do mesmo evento do Cactchô;
- headers de segurança reforçados: CSP compatível com WebAssembly, HSTS e COOP;
- cache longo para assets versionados;
- noindex/nofollow e robots bloqueando indexação permanecem durante staging.

## Decisões deliberadas
- CSS principal NÃO foi adiado. Isso evitaria poucos milissegundos, mas poderia causar FOUC/layout shift.
- Trusted Types não foi forçado nesta etapa porque pode quebrar bibliotecas de terceiros; CSP já oferece ganho de segurança sem esse risco.
- O arquivo .riv não foi modificado nesta etapa.

## Gates antes do push
- npm install (sincronizar package-lock com 0.6.1);
- npm run build;
- npm run preview;
- regressão PC + iPhone;
- favicon na aba;
- Cactchô carrega e fallback não aparece em fluxo normal;
- personalização, pedido e WhatsApp;
- git diff --check;
- git status.
